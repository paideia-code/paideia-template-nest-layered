# paideia-template-nest-layered

Template de aplicación REST con NestJS y arquitectura interna por capas,
organizada por módulos de negocio.

Incluye el módulo `enrollments`, con controllers para la entrada HTTP,
services para la lógica de aplicación y model para entidades y repositorios.

El almacenamiento inicial es en memoria: los datos se pierden al reiniciar.
